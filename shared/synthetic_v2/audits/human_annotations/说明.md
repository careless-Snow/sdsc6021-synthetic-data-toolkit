## note 怎么写

`note` 是选填，用于记录你确实观察到的具体问题。没有明确问题可以留空，无需给每张图找缺陷。中文短句即可，优先写成“部位 + 现象”。

下面的例子结合这批图片中出现的现象整理，供选择措辞；每一条都应以当前图片的实际内容为依据。

| 观察到的情况 | 可以填写的 note |
|---|---|
| 头部、肢体或其他部位明显重复 | 头部结构异常，出现两个头部；腿部有重复或粘连 |
| 身体部位的连接明显异常 | 躯干和四肢连接异常；颈部与身体连接不自然 |
| 机械部件的连接或排列异常 | 机翼与机身连接不自然；起落架位置不自然 |
| 车身局部轮廓错乱 | 车门轮廓和接缝不自然；车尾局部结构不自然 |
| 比例明显不协调 | 头身比例不协调；发动机相对机身明显过大 |
| 透视或左右位置关系明显不协调 | 透视关系略有失真；两侧机翼位置不协调 |
| 局部肢体或细节变形 | 脚趾融合，数量难以辨认；腿部局部结构错乱 |
| 局部出现异常毛束 | 下颌处出现异常长毛，类似胡须 |
| 文字或纹理细节不清楚 | 车牌文字模糊；机身文字难以辨认 |
| 遮挡或模糊影响观察 | 脚部被遮挡，结构看不清；主体轮廓模糊，类别难以确定 |

“结构错乱”“结构异常”可以使用；能看清具体部位时，尽量补充部位名称，例如“车门结构不自然”。如果只能确认边缘或连接看不清，直接写“轮廓不清晰”“连接关系不清楚”，保留观察中的不确定性。

## 哪些情况可以不写

- 正常的画面裁切、特写或背景虚化，目标类别仍清楚可辨。
- 颜色鲜艳、黑白画面、画面不够好看，且没有明确的结构或识别问题。
- 正常的姿态差异、多只动物同框，或被其他部位遮挡的肢体。
- 你暂时无法确定是否异常的生物特征、车型或船型。

对这些情况，`note` 留空即可。若希望记录少见的外观，可以客观描述，例如“船上带有风帆”“尾羽呈分叉状”；仅凭外观少见，不直接认定它是生成错误。

## 几个判断边界

- **类别可辨与结构正常分别判断。**明显是马，但出现两个头部，仍可填 `correct`，并备注“出现两个头部”。`correct` 只表示目标类别清楚可辨。
- **看不见不等于缺失。**脚、翅膀或发动机可能被遮挡、透视缩短或画面裁切。只有能明确确认结构缺失时才写“缺失”；证据不足时可写“该部位不可见”或留空。
- **外形相似不等于部位重复。**鸟的分叉尾羽、动物身上的斑纹等，应先确认具体结构，再写“多了一条尾巴”“多了一只眼睛”。
- **结构问题若严重到无法确定类别，填 `uncertain`。**备注说明是什么部位或遮挡导致无法判断。
- **目标明显不符或缺失，填 `wrong`。**备注可写“主要对象为其他类别”或“未见目标对象”；类别问题应体现在 `judgment` 中。

`note` 的条数只表示你写了多少条备注，不直接等于全部缺陷的数量或整体图像质量不合格率。
